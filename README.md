# Casual Decision Variants (CDVs)

This repository implements and evaluates **Casual Decision Variants (CDVs)** - a novel approach for improving causal inference in business processes by partitioning data based on process behavior patterns.

It is **not an extension of [RealCause](https://github.com/bradyneal/realcause)**. Instead, RealCause is vendored in as a dependency/tool that is used to build a realistic, semi-synthetic benchmark for the Sepsis experiment track (fitting a generative model to real event-log data so that ground-truth causal effects are known). The synthetic experiment track is fully independent of RealCause: it uses its own data-generating process (`cdv_utils/synthetic_dgp.py`) with no RealCause models involved.

Beyond the CDV method implementation itself, this repository also contains the experiment code, generated artifacts, and results (tables, figures, and raw outputs) produced when applying CDVs to both tracks.

## Overview

This repository provides:

- **The CDV method**: partitioning data based on process behavior patterns to reduce confounding from process heterogeneity
- **Process variant analysis**: Identifying and leveraging case process patterns
- **Variant-specific causal modeling**: Training separate models for different process behaviors
- **Comparative evaluation**: Benchmarking global vs. variant-specific approaches
- **Business process mining integration**: Specialized tools for event log analysis
- **Two experiment tracks**: a real-world Sepsis track (built on top of RealCause) and a fully synthetic track (independent of RealCause)
- **Results**: the tables, figures, and experiment artifacts (see `results/` and `plots/`) generated by running the method

## Key Innovation: Casual Decision Variants (CDV)

Casual Decision Variants represent different behavioral patterns in business processes. Instead of training a single global model on all data, this approach:

1. **Identifies process patterns** based on pre-treatment activity sequences and measurements
2. **Partitions data** into homogeneous variants with similar process behaviors
3. **Trains specialized models** for each variant (with global fallback)
4. **Evaluates causal effects** using variant-specific vs. global approaches

This methodology can improve causal inference accuracy by reducing confounding from process heterogeneity.

## Repository Structure

All experiments live in the `cdv_experiments/` folder, split into two tracks: `sepsis/` (real-world Sepsis event log) and `synthetic/` (synthetic DGP with controllable heterogeneity). Each track is a numbered sequence of notebooks that prepare data, train models, run the multi-seed experiment, and analyze results.

### `cdv_experiments/sepsis/`

- **00_data_preparation.ipynb** — Reads the raw Sepsis XES event log, extracts admission decisions (treatment), pre-admission activities/measurements (features), and produces `cdv_experiments/sepsis/artifacts/sepsis_cases.csv`. Run once before any other sepsis notebook.
- **01_realcause_training.ipynb** — Trains a TarNet generative model on the Sepsis dataset and saves the checkpoint used by the experiment notebook. Run once.
- **02_experiment.ipynb** — Runs the multi-seed experiment comparing five methods (`GLOBAL_SENTINEL`, `GLOBAL_MISSINGNESS`, `GLOBAL_MISSINGNESS_CDV`, `CDV_SEPARATE`, `MATCHED_RANDOM_PARTITIONS`) across multiple causal learners (DR_RF, S_RF, S_Linear, T_RF, X_RF, Double_ML), checkpointing after every seed.
- **03_analysis.ipynb** — Builds the primary manuscript tables/figures (DR-RF only): ATE/CATE MSE with confidence intervals, paired-difference forest plots, and CDV support/overlap diagnostics.
- **04_supplementary.ipynb** — Full learner grid, oracle-selected estimator results, ranking metrics, and random-partition placebo analysis for the supplementary material.

### `cdv_experiments/synthetic/`

- **00_dgp_exploration.ipynb** — Explores the synthetic data-generating process, sub-group distributions, and the heterogeneity (`alpha`) sweep. Reference notebook only; no outputs saved.
- **01_experiment.ipynb** — Runs the full outer-seed × alpha experiment comparing the same five methods as the Sepsis track.
- **02_analysis.ipynb** — Builds the primary manuscript figures/tables (DR-RF only): ATE/CATE MSE vs. alpha scissors charts, paired-difference tables, and ranking metrics.
- **03_supplementary.ipynb** — Full learner grid, oracle-selected estimator results, per-estimator CDV advantage, and CDV support statistics for the supplementary material.

Each track is configured via `sepsis/config.py` and `synthetic/config.py` (see `cdv_experiments/CONFIG_GUIDE.md`), and shared logic (CDV discovery, estimators, metrics, plotting) lives in `cdv_experiments/helpers/`.

Note the difference in how RealCause is used between tracks: the Sepsis track uses RealCause (`models/`, `train_generator.py`, etc.) to fit a generative model to real event-log data so that ground-truth causal effects are known. The synthetic track does not use RealCause at all - it generates data directly from `cdv_utils/synthetic_dgp.py`.

## CDV Utils Package

The `cdv_utils/` package provides utilities used by the `cdv_experiments/` notebooks:

- `sepsis_loading.py`: Event log data processing
- `feature_extraction.py`: Business process feature engineering
- `analysis_utils.py`: Variant frequency and distribution analysis
- `transform_utils.py`: RealCause dataset preparation and cleaning
- `generator_validation.py`: RealCause model training, selection, and validation
- `synthetic_dgp.py`: Synthetic data-generating process used by the synthetic track

## Results

Generated artifacts and results from running the CDV method are stored in this repository rather than a separate downstream project:

- `results/`: Raw experiment outputs (pickled run results, statistical tables, and summary JSON files) for the synthetic and Sepsis tracks
- `plots/`: Figures generated from the results (bias-variance scatter plots, scissors charts, ranking metrics, and causal analysis plots)

These are produced by the analysis notebooks in `cdv_experiments/sepsis/` and `cdv_experiments/synthetic/` and are used directly in the accompanying manuscript.
