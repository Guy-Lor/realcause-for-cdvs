\subsection{Synthetic DGP: Full Specification}
\label{app:dgp}
Shared exogenous variables (identical across all subgroups): $X_1\sim\mathrm{Uniform}(0,5)$, $X_2\sim\mathrm{Bernoulli}(0.5)$. Each of the six subgroups $v$ defines its own feature-generation, propensity, and outcome equations (Tables~\ref{tab:app_dgp_features} and~\ref{tab:app_dgp_outcomes}); all subgroup-specific feature draws use $|\mathcal{N}(\mu,\sigma)|$ (half-normal). Propensity is $P(T{=}1\mid\cdot)=\mathrm{sigmoid}(\text{logit})$. Outcomes are completed as $Y(0)=f_v(\cdot)+\varepsilon$ with $\varepsilon\sim\mathcal{N}(0,2.0)$, $Y(1)=Y(0)+\tau_v$, $T\sim\mathrm{Bernoulli}(P(T{=}1\mid\cdot))$, and observed $Y=(1-T)Y(0)+T\,Y(1)$; treatment effects follow $\tau_v(x)=5+\alpha\Delta_v(x)$. The ground truth used for CATE evaluation is the realized, noise-free potential-outcome contrast $\mathrm{ite}=\tau_v(x)$ for each unit's own $(x,v)$ draw, following the standard individual-treatment-effect (ITE/PEHE) evaluation convention: deterministic given $(x,v)$, with no separate treatment-effect noise. This individual-level quantity is not, in general, the $S$-conditional estimand $\tau^\star(s)=\mathbb E[Y(1)-Y(0)\mid S{=}s]=\sum_v\tau_v(x)P(v\mid S{=}s)$ used in the identification argument: for SG0a/SG0b, $v$ is latent and both mechanisms share the same observed history $S$ and propensity but not the same $\tau_v$, so scoring against $\mathrm{ite}$ introduces a latent-mechanism-driven residual on CDV~3/SG0 cases that no evaluated estimator can eliminate, since none observes $v$. This residual is common to every method (CDV and global alike), so it does not bias the relative comparison, but it does mean the reported CATE-MSE is a stricter, standard PEHE-style benchmark rather than an estimate of $\mathbb E[(\hat\tau(x)-\tau^\star(s))^2]$.

Variable-presence patterns (which pre-decision variables a case exposes) map directly to the retained CDVs of the main-text Support and Overlap section: CDV~1 = SG1 (observes $X_1,X_2,E,V$), CDV~2 = SG2 ($X_1,X_2,V,E,Z_2$), CDV~3 = SG0a $\cup$ SG0b pooled ($X_1,X_2,V,Z_1$; the two share an identical observed feature set and propensity function but differ in their feature-generation, outcome, and effect equations, so CDV~3 is not perfectly causally homogeneous), and \textsc{Other} = SG3 $\cup$ SG4 $\cup$ SG5 pooled (below the coverage threshold).
